# Elite Commercial Cleaning — Website Redesign Concept

Redesign concept for [Elite Commercial Cleaning L.L.C.](https://www.elitecleaningidaho.com/), a commercial cleaning company in Idaho Falls, ID. It keeps the content of the current site (services, facility programs, the Elite Advantage, contact details) in a cleaner one-page layout.

**Live:** https://thinkfirstjason.github.io/elite-commercial-cleaning/

- Single static `index.html`, no build step
- Type: Archivo (Google Fonts), falling back to Helvetica Neue / Helvetica / Arial
- Colors meet WCAG AA: body text 6.3:1 or higher, UI borders 3:1 or higher
- The quote form builds a pre-filled email to the company's inbox, as the current site does
- Photos from [Pexels](https://www.pexels.com) (Pexels License)

Logo and business details belong to Elite Commercial Cleaning L.L.C. This is an unsolicited concept, not the company's official site.

Copy fixes from the current site: removed the "corporate San Francisco" line and the "CCall anytime" typo. The current site's social links point to generic homepages (facebook.com, etc.), so they're left out until real profile URLs are available.
